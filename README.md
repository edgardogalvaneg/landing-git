Aprendiendo a usar git 
En este proyecto aprendo a usar la herramienta de git y git hub 
El objetivo es aprender a ejecutar los comandos de manera correcta aprender a hacer commit, el uso de ramas, crear repositorio,issues y demás
La estructura de repositorio consta de un archivo readme.md y entrega.md una carpeta proyecto la cual contiene un index.html y styles.css y un archivo .txt
